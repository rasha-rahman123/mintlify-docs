---
title: Create Job
description: Submit a batch of tracks for asynchronous analysis.
---

## Endpoint

```http
POST /bulk/jobs
```

## Request body

```json
{
  "name": "Q1 Catalog Scan",
  "items": [
    { "item_id": "track-001", "url": "https://cdn.example.com/01.mp3" },
    { "item_id": "track-002", "url": "https://cdn.example.com/02.mp3" }
  ],
  "webhook_url": "https://yourapi.com/webhooks/hs"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | Human-readable label for the job |
| `items` | array | Yes* | Array of track items (max 10,000 per request) |
| `manifest_url` | string | Yes* | URL to an NDJSON manifest file for large batches |
| `webhook_url` | string | No | Endpoint to receive `job.complete` and `track.complete` events |

*Provide either `items` or `manifest_url`.

### Item fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `item_id` | string | Yes | Your identifier — returned in results |
| `url` | string | Yes | Publicly accessible audio URL |
| `metadata` | object | No | Arbitrary key-value pairs, returned in results |

## Example request

<CodeGroup>
```bash cURL
curl -X POST https://app.jobsbyhumans.com/bulk/jobs \
  -H "Authorization: Bearer $HS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Q1 Catalog Scan",
    "items": [
      { "item_id": "track-001", "url": "https://cdn.example.com/01.mp3" },
      { "item_id": "track-002", "url": "https://cdn.example.com/02.mp3" }
    ],
    "webhook_url": "https://yourapi.com/webhooks/hs"
  }'
```

```ruby Ruby
require "faraday"

client = Faraday.new(url: "https://app.jobsbyhumans.com") do |f|
  f.request :json
  f.response :json
  f.headers["Authorization"] = "Bearer #{ENV.fetch('HS_API_KEY')}"
end

job = client.post("/bulk/jobs", {
  name: "Q1 Catalog Scan",
  items: [
    { item_id: "track-001", url: "https://cdn.example.com/01.mp3" },
    { item_id: "track-002", url: "https://cdn.example.com/02.mp3" },
  ],
  webhook_url: "https://yourapi.com/webhooks/hs",
}).body

puts job["job_id"]
```

```python Python
import os, requests

job = requests.post(
    "https://app.jobsbyhumans.com/bulk/jobs",
    headers={"Authorization": f"Bearer {os.environ['HS_API_KEY']}"},
    json={
        "name": "Q1 Catalog Scan",
        "items": [
            {"item_id": "track-001", "url": "https://cdn.example.com/01.mp3"},
            {"item_id": "track-002", "url": "https://cdn.example.com/02.mp3"},
        ],
        "webhook_url": "https://yourapi.com/webhooks/hs",
    },
).json()

print(job["job_id"])
```
