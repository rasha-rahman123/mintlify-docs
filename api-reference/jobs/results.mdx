---
title: Get Job Results
description: Retrieve per-track results for a completed bulk job.
---

## Endpoint

```http
GET /bulk/jobs/{job_id}/results
```

Results stream as **newline-delimited JSON (NDJSON)** — one record per line. Each record is the same shape as the [single-track response](/api-reference/tracks/analyze), with an extra `item_id` field.

## Query parameters

| Param | Values | Description |
|-------|--------|-------------|
| `detail` | `full` | Adds `scores`, `risk_segments`, and `tier_verdicts` to each record |

## Example request

<CodeGroup>
```bash cURL
curl https://app.jobsbyhumans.com/bulk/jobs/job_abc123/results \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import json, os, requests

response = requests.get(
    "https://app.jobsbyhumans.com/bulk/jobs/job_abc123/results",
    headers={"Authorization": f"Bearer {os.environ['HS_API_KEY']}"},
    stream=True,
)

for line in response.iter_lines():
    if line:
        record = json.loads(line)
        print(record["item_id"], record["verdict"], record["confidence"])
```

```typescript TypeScript
const response = await fetch(
  "https://app.jobsbyhumans.com/bulk/jobs/job_abc123/results",
  { headers: { "Authorization": `Bearer ${process.env.HS_API_KEY}` } }
);

const text = await response.text();
for (const line of text.trim().split("\n")) {
  const record = JSON.parse(line);
  console.log(record.item_id, record.verdict, record.confidence);
}
```
</CodeGroup>

## Response (NDJSON)

Each line is one record:

```json
{"item_id":"track-001","verdict":"human","confidence":0.62,"origin":"human","origin_confidence":null,"risk_timeline":[0.04,0.07,0.05],"duration_sec":214.0,"model_version":"2026-04-29","processed_at":"2026-04-29T10:43:01Z"}
{"item_id":"track-002","verdict":"ai","confidence":0.91,"origin":"suno","origin_confidence":0.82,"risk_timeline":[0.88,0.93,0.91],"duration_sec":187.4,"model_version":"2026-04-29","processed_at":"2026-04-29T10:43:04Z"}
```

| Field | Type | Description |
|-------|------|-------------|
| `item_id` | string | Identifier you supplied when submitting the job |
| `verdict` | `"ai"` \| `"human"` \| `"uncertain"` | Final classification |
| `confidence` | float (0–1) | Confidence in the verdict |
| `origin` | string \| null | Detected generator when AI |
| `origin_confidence` | float (0–1) \| null | Confidence in origin attribution |
| `risk_timeline` | float[] | Per-window AI probability |
| `duration_sec` | float | Audio duration in seconds |
| `model_version` | string | Detector calibration version |
| `processed_at` | string (ISO 8601 UTC) | When analysis completed |

Failed items return `{"item_id": "...", "status": "failed", "error": "..."}`.

## Detail = full

Add `?detail=full` to extend each record with `scores`, `risk_segments`, and `tier_verdicts`:

```bash
curl "https://app.jobsbyhumans.com/bulk/jobs/job_abc123/results?detail=full" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

The added blocks are identical to the [single-track `detail=full` response](/api-reference/tracks/analyze#detail-full).
