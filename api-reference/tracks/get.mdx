---
title: Get Track
description: Retrieve a previously analyzed track by ID.
---

## Endpoint

```http
GET /api/v1/tracks/{track_id}
```

## Example request

```bash
curl https://app.jobsbyhumans.com/api/v1/tracks/trk_xyz789 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Response

Returns the same shape as the polled `/api/jobs/{id}/status` result, plus an `id` field.

```json
{
  "id": "trk_xyz789",
  "verdict": "human",
  "confidence": 0.62,
  "origin": null,
  "origin_confidence": null,
  "risk_timeline": [0.04, 0.07, 0.05, 0.06],
  "duration_sec": 214.3,
  "model_version": "2026-04-29",
  "processed_at": "2026-04-29T10:43:01Z"
}
```

Pass `?detail=full` to add `risk_segments` and `tier_verdicts`. See [Analyze Track](/api-reference/tracks/analyze) for the full field reference.
