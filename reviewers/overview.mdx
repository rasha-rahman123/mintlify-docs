## A full result

One track, exactly as the API returns it. Every field is explained in [The result, field by field](/reviewers/result-fields).

```json Ultra scan result
{
  "item_id": "track-001",
  "analysis_type": "full",
  "verdict": "ai",                                        // the recording-level call
  "verdict_basis": ["vocal"],                             // what fired: the isolated vocal
  "mix_verdict": "human",                                 // the whole mix on its own — a hybrid
  "confidence": 0.86,
  "industry_label": "ai_generated",
  "industry_label_status": "meets_definition",
  "industry_label_basis": ["AI lead vocal performance"],  // quotable as-is
  "origin": "suno",
  "origin_confidence": 0.71,
  "origin_map_evidence": "https://…/track-001-map.png",
  "stems": {
    "vocal": {
      "verdict": "ai", "ai_score": 0.98, "fpr_tier": "0.01",
      "tier_verdicts": { "press_safe": null, "human_safe": "ai", "recall": "ai" }
    },
    "instrumental": {
      "verdict": "human", "ai_score": 0.11,
      "tier_verdicts": { "press_safe": "human", "human_safe": "human", "recall": "ai" }
    }
  },
  "tier_verdicts": { "press_safe": "human", "human_safe": "human", "recall": "ai" },
  "risk_timeline": [0.0, 0.0, 0.9, 0.88],                 // where in the track to listen
  "duration_sec": 210.4,
  "model_version": "hsv-1.0.0",                           // which engine produced this scan
  "processed_at": "2026-07-21T04:15:00Z"
}
```

Reading this one in a sentence: the whole mix sounds human, but the isolated vocal is called AI at a strict threshold — so the recording is labeled AI-Generated on the basis of an AI lead vocal, with the risky region in the second half of the track.
