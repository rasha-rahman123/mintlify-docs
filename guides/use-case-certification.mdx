## `press_safe` tier

The `press_safe` tier is calibrated at **~0% FPR on both clean and hard-negative human tracks**. Use it when a false positive carries reputational or legal consequences: royalty-pool submissions, sync licensing, human-only platform ingestion.

`press_safe` is returned in `tier_verdicts` when you call the API with `?detail=full`.

| Value | Action |
|-------|--------|
| `"human"` | Issue certification |
| `"ai"` | Reject — acoustic evidence of AI origin |
| `"uncertain"` | Inconclusive — escalate to human expert review, do not certify |

## Flow

```
Track submitted
     │
     ▼
Analyze with HumanStandard (?detail=full)
     │
     ▼
┌──────────────────────────┐
│ tier_verdicts.press_safe │
└──────────────────────────┘
     │
     ├── "human"     → ✅ Issue certification
     ├── "ai"        → ❌ Reject / flag as AI-origin
     └── "uncertain" → ⚠️  Escalate to human expert review
```

## Implementation

```python Python
import os, time, requests

API = "https://app.jobsbyhumans.com"
H = {"Authorization": f"Bearer {os.environ['HS_API_KEY']}"}

def analyze_full(audio_url: str) -> dict:
    job = requests.post(f"{API}/api/analyze", headers=H, json={"url": audio_url}).json()
    while True:
        s = requests.get(f"{API}/api/jobs/{job['job_id']}/status?detail=full", headers=H).json()
        if s["status"] == "complete":
            return s["result"]
        time.sleep(2)

def certify_track(audio_url: str) -> dict:
    result = analyze_full(audio_url)
    press_safe = (result.get("tier_verdicts") or {}).get("press_safe")

    if press_safe == "human":
        return {
            "decision": "certified",
            "confidence_tier": "press_safe",
            "confidence": result["confidence"],
            "model_version": result["model_version"],
            "processed_at": result["processed_at"],
            "message": "Acoustic evidence consistent with human origin at press-safe confidence.",
        }

    if press_safe == "ai":
        return {
            "decision": "rejected",
            "confidence_tier": "press_safe",
            "confidence": result["confidence"],
            "origin": result.get("origin"),
            "model_version": result["model_version"],
            "message": "Acoustic evidence of AI-generated origin detected.",
        }

    return {
        "decision": "review",
        "confidence_tier": "inconclusive",
        "human_safe_verdict": (result.get("tier_verdicts") or {}).get("human_safe"),
        "model_version": result["model_version"],
        "message": "Insufficient acoustic evidence at press-safe threshold. Expert review required.",
    }
```

```typescript TypeScript
const API = "https://app.jobsbyhumans.com";
const H = { Authorization: `Bearer ${process.env.HS_API_KEY}` };

async function analyzeFull(audioUrl: string): Promise<any> {
  const job = await fetch(`${API}/api/analyze`, {
    method: "POST", headers: { ...H, "Content-Type": "application/json" },
    body: JSON.stringify({ url: audioUrl }),
  }).then(r => r.json());
  while (true) {
    const s = await fetch(`${API}/api/jobs/${job.job_id}/status?detail=full`, { headers: H }).then(r => r.json());
    if (s.status === "complete") return s.result;
    await new Promise(r => setTimeout(r, 2000));
  }
}

async function certifyTrack(audioUrl: string) {
  const result = await analyzeFull(audioUrl);
  const pressSafe = result.tier_verdicts?.press_safe;

  if (pressSafe === "human") {
    return { decision: "certified", confidence_tier: "press_safe", confidence: result.confidence, model_version: result.model_version, processed_at: result.processed_at };
  }
  if (pressSafe === "ai") {
    return { decision: "rejected", confidence_tier: "press_safe", confidence: result.confidence, origin: result.origin, model_version: result.model_version };
  }
  return { decision: "review", confidence_tier: "inconclusive", human_safe_verdict: result.tier_verdicts?.human_safe, model_version: result.model_version };
}
```

## What to include in a certification report

| Field | Value |
|-------|-------|
| `confidence_tier` | `"press_safe"` |
| `confidence` | e.g. `0.94` |
| `model_version` | e.g. `"2026-04-29"` — the calibration version that produced this result |
| `processed_at` | ISO 8601 timestamp |
| `origin` | `null` for human verdicts; the detected generator for AI |

This creates an auditable chain: which model version made the call, at what confidence, and when.

## Handling `"uncertain"` press-safe (expert review)

When `press_safe` is `"uncertain"`, there isn't enough acoustic evidence for a press-safe determination. Recommended:

1. Check `tier_verdicts.human_safe` — if it's `"human"`, the track falls below press-safe but shows no AI evidence at the human-safe threshold.
2. Review `risk_segments` (from `?detail=full`) to see which sections scored elevated.
3. Route to a human expert with the full signal report (`risk_segments` from `?detail=full`).
4. Optionally request the artist provide session files or a DAW project for verification.

<Warning>
  Do not certify tracks where `press_safe` is `"uncertain"`. Issue certification only on explicit `"human"` verdicts at this tier.
</Warning>
