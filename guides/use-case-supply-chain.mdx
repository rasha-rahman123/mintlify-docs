## Tiered escalation

Pass `?detail=full` and use all three tiers in a three-layer chain. `press_safe` is the strictest gate, `human_safe` is the default, and `recall` catches borderline cases for human review.

```
Track arrives at intake
          │
          ▼
  Analyze with HumanStandard (?detail=full)
          │
          ▼
  ┌─────────────────────────────────┐
  │ Check press_safe tier (strict) │
  └─────────────────────────────────┘
          │
          ├── "ai" ──────► ❌ Auto-reject
          │                  (highest confidence AI, ~0% FPR)
          │
          └── "human"/"uncertain" ──► Check human_safe tier
                                        │
                                        ├── "ai" ──────► ❌ Auto-reject
                                        │                  (~1–2% FPR)
                                        │
                                        └── "human"/"uncertain" ──► Check recall tier
                                                                    │
                                                                    ├── "ai" ──────► 🔍 Manual review
                                                                    │                  (borderline)
                                                                    │
                                                                    └── "human"/"uncertain" ──► ✅ Approve
```

Four outcomes:
1. **Auto-reject (press chain)** — strongest AI evidence, near-zero FPR
2. **Auto-reject (distribution layer)** — high-confidence AI
3. **Manual review** — borderline, needs a human
4. **Approve** — passes all tiers

## Implementation

```python Python
import os, time, requests
from enum import Enum

API = "https://app.jobsbyhumans.com"
H = {"Authorization": f"Bearer {os.environ['HS_API_KEY']}"}

class IntakeDecision(str, Enum):
    APPROVE = "approve"
    MANUAL_REVIEW = "manual_review"
    REJECT = "reject"

def analyze_and_poll(audio_url: str) -> dict:
    job = requests.post(f"{API}/api/analyze", headers=H, json={"url": audio_url}).json()
    while True:
        s = requests.get(f"{API}/api/jobs/{job['job_id']}/status?detail=full", headers=H).json()
        if s["status"] == "complete":
            return s["result"]
        if s["status"] == "failed":
            return {"status": "failed", "error": s.get("error")}
        time.sleep(2)

def evaluate_intake(audio_url: str, item_id: str) -> dict:
    result = analyze_and_poll(audio_url)

    if result.get("status") == "failed":
        return {"item_id": item_id, "decision": IntakeDecision.MANUAL_REVIEW,
                "reason": "analysis_failed", "error": result.get("error")}

    tier = result.get("tier_verdicts") or {}

    if tier.get("press_safe") == "ai":
        return {"item_id": item_id, "decision": IntakeDecision.REJECT,
                "reason": "press_safe_ai", "confidence": result["confidence"],
                "origin": result.get("origin")}

    if tier.get("human_safe") == "ai":
        return {"item_id": item_id, "decision": IntakeDecision.REJECT,
                "reason": "human_safe_ai", "confidence": result["confidence"],
                "origin": result.get("origin")}

    if tier.get("recall") == "ai":
        return {"item_id": item_id, "decision": IntakeDecision.MANUAL_REVIEW,
                "reason": "recall_ai_borderline", "confidence": result["confidence"],
                "risk_timeline": result.get("risk_timeline")}

    return {"item_id": item_id, "decision": IntakeDecision.APPROVE,
            "confidence": result["confidence"]}
```

```typescript TypeScript
type IntakeDecision = "approve" | "manual_review" | "reject";

const API = "https://app.jobsbyhumans.com";
const H = { Authorization: `Bearer ${process.env.HS_API_KEY}` };

async function analyzeAndPoll(audioUrl: string): Promise<any> {
  const job = await fetch(`${API}/api/analyze`, {
    method: "POST", headers: { ...H, "Content-Type": "application/json" },
    body: JSON.stringify({ url: audioUrl }),
  }).then(r => r.json());

  while (true) {
    const s = await fetch(`${API}/api/jobs/${job.job_id}/status?detail=full`, { headers: H })
      .then(r => r.json());
    if (s.status === "complete") return s.result;
    if (s.status === "failed") return { status: "failed", error: s.error };
    await new Promise(r => setTimeout(r, 2000));
  }
}

async function evaluateIntake(audioUrl: string, itemId: string) {
  const result = await analyzeAndPoll(audioUrl);
  if (result.status === "failed") {
    return { item_id: itemId, decision: "manual_review" as IntakeDecision, reason: "analysis_failed" };
  }
  const tier = result.tier_verdicts ?? {};
  if (tier.press_safe === "ai") return { item_id: itemId, decision: "reject" as IntakeDecision, reason: "press_safe_ai", confidence: result.confidence, origin: result.origin };
  if (tier.human_safe === "ai") return { item_id: itemId, decision: "reject" as IntakeDecision, reason: "human_safe_ai", confidence: result.confidence, origin: result.origin };
  if (tier.recall === "ai") return { item_id: itemId, decision: "manual_review" as IntakeDecision, reason: "recall_ai_borderline", confidence: result.confidence, risk_timeline: result.risk_timeline };
  return { item_id: itemId, decision: "approve" as IntakeDecision, confidence: result.confidence };
}
```

## What to show human reviewers

When a track lands in manual review, surface the key signals:

| Signal | Display | Means |
|--------|---------|-------|
| `confidence` | Score bar 0–1 | Confidence in the verdict |
| `risk_timeline` | Waveform heatmap | Which sections triggered |
| `origin` | Badge | Predicted generator |
| `scores` | Mini bars | Individual signal scores from `?detail=full` |
| `tier_verdicts` | Three-light indicator | Where the verdict lands at each operating point |

## Bulk intake pipeline

For high volume, use bulk jobs with a webhook:

```python
def submit_intake_batch(tracks: list[dict]) -> str:
    job = requests.post(f"{API}/bulk/jobs", headers=H, json={
        "name": f"Intake {datetime.utcnow().date()}",
        "items": [{"item_id": t["id"], "url": t["url"]} for t in tracks],
        "webhook_url": "https://yourapi.com/webhooks/hs",
    }).json()
    return job["job_id"]
```

The webhook payload uses the same field names — `verdict`, `confidence`, `tier_verdicts` — as the polling response.

## Tuning the policy

**Stricter (fewer false negatives, more manual review)**:
- Treat `tier_verdicts.recall == "ai"` as auto-reject instead of manual review.

**More permissive (less manual review)**:
- Only auto-reject when `tier_verdicts.press_safe == "ai"`. Send `human_safe == "ai"` to manual review instead.

<Tip>
  Run the three-layer escalation for a few weeks, then measure your manual-review queue's overturn rate. If reviewers are overturning too many auto-rejects, tighten. If they're mostly confirming AI, automate more.
</Tip>
